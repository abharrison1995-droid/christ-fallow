# Christ Fallow — Agent Guide & Codebase Map

> Stone Age 3D civilization, base-building, religion, diplomacy, and tactical combat game in **Godot 4.3 (Forward+ / Vulkan, GDScript)**.
> Base viewport is `1600×900` with `canvas_items` stretch and `expand` aspect. 3D visuals combine imported GLBs with procedural GDScript meshes and effects. The asset generators use Blender 4.5 LTS.

## Working in this project

- **Fresh checkout & cross-device setup:** Start with the [Continuing on Another Device & Plan Map](docs/HANDOFF.md#continuing-on-another-device--plan-map) guide. On a new clone, run `$godot --headless --editor --path . --import` once so `.godot/` populates before launching Forward+ tests.
- Run the source project from `project.godot` with the Godot 4.3 console executable (`$env:GODOT_EXE`). [Windows release plan](docs/ROADMAP.md#slice-10c--staged-3d-assets--release-packaging)
- Local Git is initialized on `main` with `.gitignore` excluding `.godot/`, `captures/`, `qa_out/`, `tmp/`, `*.lnk`, and temp/cache files while tracked `.import` files and `assets/` travel cleanly in Git; checkpoint cleanly before multi-file refactors.
- Follow the affected feature from its player-facing entry point through the state change and the HUD update. Several features have both a button and a hotkey. Check both when editing their shared behavior.
- Use the smallest check that exercises the changed behavior. Record the command, gameplay path, and result so the next agent can reproduce it. Keep temporary probes, test saves, and showcase images outside the project unless they belong in a lasting test or asset.

## Runtime flow

1. The title owns its front-end screens. `CampaignSession` mounts `scenes/main.tscn` for New Game, Continue, or Load, then removes it and clears the campaign references on Return to Title. The world, command system, player controller, and HUD register in `GameState` during `_ready()`.
2. `GameState.start_new_campaign()` initializes faction data, diplomacy, the clock, and guide flags, populates the world, then activates the HUD. `game_started` fires during initialization before entities are spawned. Code that needs the leader or live buildings must wait for population.
3. `GameState` owns campaign rules, including guide progression, manual and conquest pause, and player role and faith actions. Live entities are children of the world containers. Use `get_faction_units()` and `get_faction_buildings()` for faction queries and the faction controller for standard spawns.
4. Continue, Load Game, `F10`, and Pause → Load Campaign call `GameState.load_game()`. `CampaignStorage` reads and writes the save. `CampaignSave` validates it before the live campaign changes. `GameState` selects the saved layout, then the world restores terrain, entities, leader attachment, and any rider. `campaign_loaded` follows combat command restoration and precedes any pending conquest modal. Review each entity's `serialize()` alongside `restore_snapshot()` and verify older saves with missing fields.
5. The HUD routes campaign shortcuts. Drawer views own their selection and focus, and `CampaignOverlays` owns pause, settings, confirmation, conquest, and results screens. `PlayerController` handles world input and consults `blocks_world_input()`. `Preferences` applies screen, audio, motion, and world presentation settings independently of the campaign save.

1. **Opening Peace Buffer & Awakening Guide**:
   - New campaigns start with `bandit_grace_remaining = BANDIT_GRACE_DURATION` (`210.0s`). This gates bone-cave spawns and autonomous rival raids. Rival colony routines still run, and explicit ally raid orders use a separate path.
   - The 5-step **Awakening Guide** tracks recruitment -> campfire founding -> gather + role assignment -> constructed `SLEEPING_HUT` (`[B]` place + `[E]` assist) -> leader cleave/javelin practice, awarding `+10 Food, +10 Wood, +5 Flint` on completion. `AwakeningGuide.get_objective_target()` drives the 3D `TutorialBeacon` (ground ring, diamond/chevron marker, 3D directional ground pointer `_leader_pointer` shown when `dist > 3.2 m`, and proximity prompts `[E] Recruit`, `[E] Harvest`, `[E] Help Build`, and `[LMB] Place Here` during Steps 2/4 build mode within `8.0 m`), HUD checklist & `Build`/`Colony` tab highlights, `BuildDrawer` (`RECOMMENDED` badge, auto-selection, and gold `Place` button highlight), `ColonyDrawer` (Step 3 `Builder / Crafter` role dropdown and Workforce `+` button highlights), and Valley Radar ring. Clicking **Skip** hides the guide and highlights without cancelling the Peace Buffer.
2. **Villager Self-Defense**:
   - Unarmed civilians use `unarmed_attack_damage` (`3.0..7.5` raw, halved for children) and `"UNARMED_PUNCH"` (`1.65m` reach, `1.15s / attack_speed_mult` cooldown) when cornered (`<= 2.35m`), recently struck by `_self_defense_target` (`<= 4.2m`), or defending camp (`<= 4.5m`). Weapon/offhand mounts are hidden briefly (`_unarmed_punch_vis_timer`) so workers punch bare-handed.
3. **Factions & Diplomacy**:
   - `-3` Wounded (rescue or timed defection into `6`), `-2` Rebels, `-1` Wild Wanderers (`E` to recruit), `0` Player Tribe, `1..4` Rival Tribes, `5` Nomadic Cavemen (permanently hostile), `6` Outcast Rebels.
   - `E` near a settled rival leader opens their card in Diplomacy. The card reads the live representative, title, distance, and direction. `GameState` owns the truce and tributary rules. Truces block attacks, war declarations and raids through two day changes. Tributaries deliver up to eight Food and three Flint each day from available stock.
   - Player and qualifying allied victories queue conquest. A surviving village with a campfire or totem can immediately appoint an adult successor when its leader falls to a third party. Restore skips succession for pending conquest choices. Tributary settlement names a surviving representative before returning to play.
4. **Screen & HUD layout**:
   - The resource strip and objectives reserve the upper right for Valley Radar. The guide and event log sit on the left. The combat controls are docked at the bottom centre, and management panels open above them. Check layouts at both ends of the interface scale range after changing panel widths or control labels.
5. **Village Building Destruction & Hostile-Only Combat Health Bars**:
   - Buildings have four stages. Intact is above 66% HP. Damaged is above 33% and at most 66%. Critical is above 0% and at most 33%, with smoke, embers, and dimmed lights. Rubble starts at 0% HP.
   - At Stage 3 (Rubble): `is_destroyed = true`, `_col_shape.set_deferred("disabled", true)`, a one-shot wood/stone debris burst fires, stage lights and fire meshes shut down, and rubble lingers for 8.0s before sinking and queue-freeing.
   - Destroyed buildings are excluded from `GameState.get_faction_buildings()`.
   - Health bar rendering: Built with a single camera-facing billboard `QuadMesh` using an unshaded spatial shader (`instance uniform float fill_ratio`, `bar_alpha`).
   - Hostile-only display: Constructed buildings keep health bars hidden by default. Only hostile damage (checked via `GameState.is_hostile(faction_id, attacker_faction)`) activates `_combat_timer = 5.0` (smoothly fading out in the final second). Attacking a neutral rival triggers `AT_WAR` and immediately activates the hostile combat bar. Friendly repair or non-hostile interactions keep the bar hidden.
   - Blueprints (`is_constructed == false`) always display their cyan build progress bar and flash red when damaged without breaking `_flash_timer` recovery.
   - Save/load persistence: `sync_visual_from_state()` derives completed-building damage stages from HP. Unfinished blueprints retain intact holograms. `_combat_timer` defaults to 0.0, keeping completed-building health bars hidden upon loading.
6. **Headless Blender 4.5 LTS Asset Toolchain & `.glb` Contracts**:
   - Portable Blender 4.5 LTS is configured via `$env:BLENDER_EXE` (default Windows location `$env:LOCALAPPDATA\Blender\blender-4.5.16-windows-x64\blender.exe`).
   - `tools/assets/build_assets.ps1` stages the Sleeping Hut, Palisade, and base tribesman. Use `-VerifyOnly -RequireGameplayRig` for strict review without publishing. The Crag-Born and valley batches have separate commands in the [asset pipeline guide](tools/assets/README.md).
   - Current GLB coverage includes fourteen buildings, six bodies for each of seven lineages, fourteen role kits, Flintmask Scout, four scenery props, and all eight wildlife species. The Blood-Pit Arena uses procedural meshes. [Asset catalog](tools/assets/CATALOG.md)
   - Building `.glb` node contract: Root Node3D -> children `Stage_Intact`, `Stage_Damaged`, `Stage_Critical`, `Stage_Rubble` + `Collider-convcolonly` (plus `CampfireLight`, `ShamanLight`, `FlameMesh` when applicable). `FactionTrim` material slots are tinted at runtime with faction colors.
   - The Ridge Signal Tower uses `SignalLight`, `FlameMesh`, and `ArrowOrigin` in each standing stage. `BuildingEntity` launches from the active stage’s marker and releases collision and navigation when it becomes rubble.
   - Character `.glb` contract uses a 17-bone `Skeleton3D` with vertex skinning, UVs, faction trim, looping `Idle`, `Walk`, `Work`, and `Wounded` clips, and one-shot `Attack`, `Hit`, and `Death` clips. The shared lineage rigs also include `GuardIdle` and `GuardWalk`. Supported units stay on the imported rig during combat with shader-driven hit flash. Verify updates with `build_assets.ps1 -RequireGameplayRig`, `verify_crag_born.gd`, and `verify_skinned_lineages.gd`.
   - `MeshFactory.build_building_stages()` provides four stages for all fifteen building types. Blueprints (`is_blueprint == true`) and placement ghosts use tinted intact geometry. Procedural stages provide the Arena and fallbacks for imported buildings.

7. **Tribal Level, Perks & Skills System**:
   - `K` opens `PerksDrawer`, backed by `PerkSystem` and `GameState.award_xp()` / `unlock_perk()`. Tribes progress across `Lv.1..12` (`MAX_LEVEL = 12`) using `xp_for_next_level(level) = 80 + (level - 1) * 55`; each level-up awards `+1` Skill Point and heals the faction leader `+30.0 HP`.
   - `PerkSystem` defines 3 branches (*Masonry & Settlement*, *Chieftain & Lineage Might*, *Kinship & Warband Mastery*) and 12 perks (`MASTER_BUILDERS`, `STONE_FOUNDATIONS`, `GREAT_LODGES`, `MASTERWORK_DEFENCES`; `PRIMAL_VIGOR`, `WARLORDS_EDGE`, `SWIFT_STRIDE`, `DIVINE_CONDUIT`; `CALL_OF_THE_HEARTH`, `SEASONED_BLOODLINES`, `BARRACKS_DRILLMASTERS`, `BATTLE_VETERANS`).
   - Building unlock gating (`STORAGE_PIT`, `CROP_FIELD`, `BARRACKS`, `SHAMAN_SHACK`, `STANDING_STONE_GATE`, `ANIMAL_PEN`, `WATCHTOWER`) is enforced in `BuildDrawer` and `FactionController` rival AI via `GameState.is_building_unlocked()` / `get_building_lock_reason()`, while direct `PlayerController.enter_build_mode()` calls remain ungated so low-level tests can bypass UI gating.
   - Kinship perks unlock `Hire Nomad Villager` in `ColonyDrawer` (`12/10/8` Food, raising max population cap from `32` to `40/48/56`), scale recruit starting stats/morale/Rank I–II (`SEASONED_BLOODLINES`), raise Barracks max training rank past V to VI/VII/VIII while letting idle Warriors spar at Barracks (`BARRACKS_DRILLMASTERS`), and grant Training XP on live combat strikes plus stockpile auto-equip on assignment (`BATTLE_VETERANS`).
   - Settled rival tribes (`1..4`, `6`) earn XP from daily/colony progression and auto-spend Skill Points according to personality priority tables (`_auto_spend_rival_perks`).
   - At Lv.1 with 0 perks, all `PerkSystem` multipliers return `1.0` (and additive bonuses `0`, max training rank `5`, pop cap `32`, nomad cost `12`), preserving legacy `v1`–`v4` saves (defaulting missing progression fields cleanly) and baseline unit tests.

8. **Spatial Index & Valley Navigation Invariants**:
   - `GameState` owns `spatial_index` and `valley_nav`, rebuilding both via `rebuild_spatial_systems()` after `populate_new_world()` and `restore_from_save()`, and clearing both via `clear_spatial_systems()` on teardown/reset.
   - `HumanUnit`, `WildlifeEntity`, and `BuildingEntity` register in `setup()`, update XZ cells on movement (`update_unit()` / `update_wildlife()`), and unregister on death, Stage 3 rubble collapse, or `_exit_tree()`. `faction_id` and `is_leader` setters on `HumanUnit` (and `faction_id` on `BuildingEntity`) keep per-faction caches synchronized; direct `global_position` teleports in tests must call `GameState.spatial_index.update_unit(unit)` if querying immediately before the next physics tick.
   - Constructed, non-destroyed solid buildings register ref-counted obstacles in `valley_nav` and clear them on rubble collapse or `_exit_tree()`. Crop Fields and Animal Pens are walkable. Deep river cells are solid outside the active layout’s `river_crossings()`. Beyond 6 m, `HumanUnit._steer_toward()` reuses a path and refreshes it when the target moves, the obstacle revision changes, or movement stalls.

9. **Farming, Livestock & Mounts**
   - Farmers work completed Crop Fields during the daily work schedule and use the existing Food hauling route. Pen feeding and breeding consume faction Food. Surplus harvest preserves two adults of each species.
   - Deer, Tusked Boars, and Woolly Mammoths can be tamed and trained as mounts. Owned and allied livestock are protected from friendly combat. Two pen feedings train an adult. While mounted, the player controller moves the leader using the animal's capsule and synchronizes the animal and rider pose. Dismounting puts the leader in clear space and returns the animal to the herd. Restore the rider only after both wildlife and leader have been instantiated.
10. **Custom Equipment, Audio & Blood-Pit Arena (Phases 7–9)**:
   - `GameData.WEAPON_DEFS` and `ARMOR_DEFS` drive `UnitStats.derive()`, `CragBornTrial`/`HumanMeshBuilder`/`FirstPersonViewmodel` gear, `PlayerController` attacks, and player stockpile trades. Explicit armor and weapons follow the unit through role changes and Warhorn. A matching crafted replacement can raise the tier of a chosen weapon. `""` uses the default loadout and `"NONE"` records the player's unarmored choice.
   - `SoundManager` autoload manages `Master`/`Music`/`SFX` buses (`Preferences` persistence, `SettingsScreen` Audio sliders), pooled 2D/3D SFX with cooldown throttling, and `TITLE`/`PEACE_DAY`/`NIGHT`/`COMBAT`/`ARENA` crossfades. The Title ambience setting adjusts the `TITLE` track. `GameState.notify_combat_audio()` suppresses requests for `COMBAT` music during bouts so `PEACE_DAY` or `NIGHT` resumes afterward.
   - `ARENA_PIT` (`Lv.3` + `BARRACKS_DRILLMASTERS` Rank 1) has a walkable floor. `ArenaRules.allows_attack()` filters both targeting and damage at the bout boundary. Defeat converts lethal blows on the player's fighters into knockouts. Convalescence (`arena_recovery_remaining`) runs at `1.75x` near a `SHAMAN_SHACK` or `CAMPFIRE` and suspends combat and work. A mid-bout load clears opponents, combatant flags, and spectator view while retaining the saved HP and convalescence. Victories award resources, XP, gear, and `is_arena_champion` (`+15` Max HP, `1.10x` DMG) at qualifying tiers.

## Godot 4.3 & Repo Engineering Conventions

- **No `.godot` global class cache reliance**: Helper modules (`HumanMeshBuilder`, `WorldMeshBuilder`, `UnitAIRoutines`, `UnitCombatAI`, `BlessingEffects`, `DiplomacyConquestRules`, `PerkSystem`, `ArenaRules`, `HUDDrawers`, `HUDPanels`, `CombatVFX`, `TribesmanAnimator`, `Projectile3D`) are loaded via `const Foo = preload("res://...")` (without `class_name`) so scripts compile cleanly in CLI runs and fresh checkouts. Keep dependency direction strictly acyclic (helper static functions accept `u`, `state`, or `hud` untyped).
- **Godot 4.3 strict typing pitfalls**: Do NOT use `:=` when the RHS comes from untyped `Dictionary`/`Array` indexing or `node.get("prop")` (`Variant`); annotate explicit types. Never call `bool(null)`—use `== true` or `!= null`.
- **Safe child replacement**: Whenever clearing children before repopulating or loading (`world_generator.gd`, `hud_controller.gd`), call `container.remove_child(c)` before `c.queue_free()` so same-frame queries never see queued-for-free nodes.
- **Building queries** use `get_faction_buildings(faction_id)` for defaults or `get_faction_buildings(faction_id, building_type, constructed_only)` for explicit filters. Pass `""` as the second argument when filtering by construction state across all types.
- **JSON save types** use numbers decoded as `float`. The save validator normalizes faction enum IDs and counters to `int`. Save positions as numeric arrays and decode them before instantiating entities.
- **Pause is campaign state.** The HUD requests manual transitions with `GameState.set_manual_pause()`. Pending conquest owns its pause until resolved. Simulation callbacks and input handlers manage their own guards. When adding a world timer or action, check behavior before campaign start, during pause or conquest, and after victory or defeat.

## Verification on Windows

Run these from the project root. Set `$env:GODOT_EXE` if Godot 4.3 console is installed outside the default Windows location (`$env:LOCALAPPDATA\Godot\Godot_v4.3-stable_win64_console.exe`; on Linux `godot4` in `$PATH`, on macOS `/Applications/Godot.app/Contents/MacOS/Godot`).

```powershell
$godot = if ($env:GODOT_EXE) { $env:GODOT_EXE } else { Join-Path $env:LOCALAPPDATA 'Godot\Godot_v4.3-stable_win64_console.exe' }
$project = (Get-Location).Path

# Import assets in a fresh checkout.
& $godot --headless --editor --path $project --import

# Verify imported GLBs, building behavior, and the gameplay rig with Forward+.
$review = Join-Path ([System.IO.Path]::GetTempPath()) ('cf-glb-' + [guid]::NewGuid())
& $godot --path $project --quit-after 600 -s res://scripts/tools/verify_glb_assets.gd -- "--out-dir=$review" --require-gameplay-rig

# Start the project and reach the title screen.
& $godot --path $project --quit-after 420

# Render the seven showcase PNGs to a fresh output folder.
$showcase = Join-Path ([System.IO.Path]::GetTempPath()) ('christ-fallow-showcase-' + [guid]::NewGuid())
& $godot --path $project --quit-after 600 res://scenes/asset_showcase.tscn -- "--out-dir=$showcase"
```

- Use Forward+ with a display for gameplay, mesh, and screenshot checks. The headless renderer is suitable for the import command and cannot validate mesh rendering. For the showcase, verify seven PNG files and inspect the shots relevant to the change. Pass `--out-dir` explicitly because the script's default path is machine-specific.
- For a scripted gameplay probe, run `& $godot --path $project --quit-after 600 -s $testScript` with the absolute path to a `SceneTree` test script. Instantiate the title scene for player-facing flows. For campaign-only checks, instantiate `res://scenes/main.tscn`, let its nodes register, then call `GameState.start_new_campaign()` before asserting on live entities. Check console output for `SCRIPT ERROR`, `Parse Error`, engine errors, and an explicit success marker. Godot can exit with code 0 after a script error or when the frame limit is reached.
- For an opening-flow change, start a campaign, recruit three wanderers with `E`, place the Campfire through `B`, and check guide progression and the Peace Buffer. Exercise the relevant world action with the drawer open and closed when changing input routing.
- For a save change, pass a temporary absolute filename to `GameState.save_game(path)` and `GameState.load_game(path)`. For title, quick-save/load, pause, and Settings checks, set `APPDATA` for the test process to a short, isolated writable directory outside the project. This keeps `user://christ_fallow_save.json` and `user://ui_preferences.cfg` separate from player data. Check a running-campaign reload and a load from a fresh launch. Test invalid data before replacing live state.
- The checked-in [campaign UI](scripts/tools/verify_campaign_ui.gd) and [campaign save](scripts/tools/verify_campaign_save.gd) checks expect `CHRIST_FALLOW_QA_APPDATA` to match the isolated `APPDATA`. Use an empty scratch directory for each UI run. See the [refactor verification commands](docs/REFACTOR.md#implementation-verification).
